# Product Overview

This is a demo React application showcasing a premium rubber duck collection website. The application serves as a marketing landing page with modern UI/UX design patterns.

## Key Features
- Dark/light theme toggle with smooth transitions
- Responsive design optimized for mobile and desktop
- Interactive animations and hover effects
- Modern glass morphism and gradient effects
- Scroll-triggered animations using Intersection Observer
- Z-pattern layout for feature sections
- Professional product showcase with hero section

## Target Audience
The application demonstrates modern web development practices and serves as a portfolio piece or demo for:
- E-commerce landing pages
- Product marketing websites
- Modern React applications with advanced styling
